LETTER GARDEN — iPAD HOME SCREEN APP

1. Extract this ZIP.
2. Upload ALL files (including index.html, manifest.webmanifest, sw.js, and icons) to a public HTTPS host such as GitHub Pages or Netlify.
3. Open the resulting website in Safari on the iPad.
4. Tap Share > Add to Home Screen > Open as Web App (if shown) > Add.
5. Launch Letter Garden from its new Home Screen icon (not from the itch.io page).

GitHub Pages example:
- Create a public repository called letter-garden.
- Upload all extracted files to the repository root.
- Settings > Pages > Deploy from a branch > main > /(root) > Save.
- Wait for the HTTPS URL to appear, then open it in Safari.

Note: iPadOS system-level gestures cannot be disabled by a webpage. The app prevents its own page from scrolling while tracing.
